# 资产配置研究与执行框架

资产配置需要一套能长期执行、能解释失败条件的规则。方法依据见[第二层](02-第二层-类型整理/配置目标与组合风险.md)，原始证据见[第一层](01-第一层-底层资料/素材入口.md)。

1. 按用途与最晚使用日期列资金需求，区分可延后目标和必须兑现的负债；不能把全部净资产都视为可投资现金。
2. 确定风险预算。记录可接受的金额损失、收入中断时的变现需求、长期真实回报目标；为通胀、失业和医疗等冲击保留余量。
3. 选择少量能解释的暴露。写明每类资产的收益来源、主要损失机制、交易成本与流动性，再决定比例。复杂模型须相对朴素组合证明扣费后价值。
4. 同时看常态和压力情景。至少检查权益下跌、利率上升、相关性抬升、现金收入减少、提前用钱；已有养老金权益的领取条件见[制度比较](02-第二层-类型整理/制度比较与可持续性.md)，不能直接当作随时可用资产。
5. 预先写再平衡规则：检查周期、允许偏离范围、优先使用新增现金、考虑税费与最小交易规模。参数须与实际成本相匹配，不设通用神奇阈值。
6. 留存决策时的假设与结果，区分资产暴露回报和主动超额回报。目标、负债或制度变化时重新评估；单次涨跌不自动推翻长期规则。

## 工具落地前的核对顺序

先确定目标暴露，再比较实现同一暴露的少量工具。每个候选工具用一行记录下列事项，未核实的字段保留待确认。

| 核对项 | 必须能回答的问题 |
|---|---|
| 资产与结构 | 实际持有股票、债券、现货、期货还是其他基金？指数和基金代码是否混淆？ |
| 准入与渠道 | 个人账户具有什么权限？产品是否在可买名单，申购或买入是否开放？ |
| 最小资金 | 市价乘最小交易单位是多少？还需预留多少费用、汇兑或保证金资金？ |
| 资金路径 | 钱从哪个账户扣除？份额在哪里登记？卖出、可用、可取分别在何时？ |
| 回报与损失 | 收益来自利息、经营现金流还是价格变化？久期、信用、展期、汇率或溢价会造成什么损失？ |
| 比较口径 | 是否同一指数和币种？净值收益是否已扣基金内部费用？分派率是否被误当总回报？ |
| 退出与复核 | 用钱前遇休市、暂停申赎或流动性下降能否退出？规则、名单或费用改变如何复核？ |

先把确定日期的支出与可及时到账的资产匹配，再考虑承担市场波动。对于债券基础尚未建立的场景，可先用短期限高信用债券工具与长期债券工具做同一利率冲击演算；对跨境ETF增加溢价回落和人民币升值情景；对REITs同时压低分配额和卖出价；对期货使用名义敞口与追保资金测算。只有在这些损失仍处于预算内时，工具比较才有配置意义。具体机制与演算见[配置目标与组合风险](02-第二层-类型整理/配置目标与组合风险.md)。


一个可复用的决策记录至少包含：目标及期限、可投资余额、不可动用储备、风险预算、目标暴露、再平衡条件、压力测试、费用、证据日期和下次复核触发条件。所有数值由具体应用场景填写，本专题不存个人实例。

长期养老资金需要同时应对领取时间变化、购买力下降和长寿照护支出。相关机制与资金缺口测算见[养老保障风险与个人配置](【第三层】养老规划的通用计算边界.md)。
