## 材料与维护边界

公开版本包含原创研究笔记、来源索引及官方链接。第三方研报、PDF、网页副本、截图及转录、个人财务和备份留在本地；来源可访问不代表已获再分发许可。第三方资料的权利仍归原权利人，仓库内容许可仅覆盖原创部分。

应用 Content Master 组织和审阅内容：正文直接讲观点、机制、证据、条件与用法；原始出处和口径留在第一层索引。涉及未来的判断使用明确条件，不将缺少依据的制度崩溃或精确未来收入写成事实。增量维护既有笔记，保留独有条件、公式与来源，使用相对路径保持本地和 GitHub 阅读兼容。

本专题提供通用研究方法，具体配置和养老金测算需结合个人情况、参保地与适用年度规则。
