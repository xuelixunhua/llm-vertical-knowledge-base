# 技术分析专题

## 当前定位

这个目录是一个垂直知识库专题，用来展示“技术分析”如何从普通笔记、书籍整理和研报索引，转化为可长期调用的领域判断系统。

它不按传统工作区里的 `笔记/`、`素材/`、`输出/` 横向分层来读，而是按“材料在知识建设中的层级”来组织。

## 首读顺序

1. `AGENTS.md`: 本专题的读法、边界和建设规则。
2. `【第三层】期货市场技术分析.md`: 当前最重要的第三层主体材料，先从这里建立技术分析本体框架。
3. `【索引】技术分析资料索引.md`: 查看来源、材料层级和后续加工方向。
4. 当主体内容不足时，再下钻到 `02-第二层-类型整理/`。

公开仓库不包含第一层原始 PDF、回测输出或其他第三方原始材料；索引只保留来源关系和调用线索。

## 三层结构

- `【第三层】期货市场技术分析.md`: 二次整理后的技术分析主体材料。它不是普通书摘，而是对定义、假设、流派和方法工具的再组织。
- `02-第二层-类型整理/`: 已经过一次压缩的类型化材料，包括书籍笔记和自建策略实验。
- 第一层底层资料: 研报、原文、回测输出、案例型材料等。公开仓库不包含这些文件，只在索引中保留必要线索。

`【索引】技术分析资料索引.md` 是 reference，不等于第三层主体。它负责告诉后续读者和 agent：哪些来源与哪些主题有关，什么时候值得回到本地第一层材料继续处理。

## 当前范围

已纳入的技术分析主题包括：

- 技术分析定义、基本假设和适用边界
- 缠论、威科夫、周期、趋势交易等流派
- 订单流、关键 K 线、量价分析、价格形态等工具
- Bolling、RSI、RSRS、均线、指标择时和 CTA 技术指标

暂不纳入：

- 代码框架和可运行源码
- 泛动量、行业轮动、宏观择时等尚未确认属于技术分析本体的材料
- 以基本面、产业、估值或宏观逻辑为主的量化资料
