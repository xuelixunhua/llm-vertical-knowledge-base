## 趋势跟踪

**本质**：通过主动顺应市场方向，在趋势持续阶段最大化收益。

**假设**：金融市场倾向于在较长时间内保持同向运动（上涨/下跌/横盘）​，无论上涨、下跌或者横盘震荡，都算是所谓的“趋势”​。

**操作**：采用"右侧交易"原则（高位买入更高卖出/低位卖空更低平仓）；入场与退出的"滞后性"特征；承受横盘震荡阶段的持续亏损。

**盈利逻辑**：捕捉趋势性行情中的主要波段收益，通过少次数大盈利覆盖多次小亏损，典型收益分布呈"尖峰厚尾"特征。

## 策略框架

1. **分散化**：**最关键**的一个因素，跨品种/跨板块配置，降低单一品种或板块的风险冲击。
2. 仓位：基于**波动率**调整仓位，平衡组合风险敞口。
3. 周期：考虑到底要追踪多长期限的趋势，比如到底是一两周的趋势，还是5～8周的趋势。这个决定策略收益特征。
4. 风险水平：要在风险与收益之间选择一个平衡点。承担的风险越高，就可能会获得更多的回报。
5. 策略组合：长期来看，将有助于平滑短期上的业绩波动。

### 评价指标

#### 策略收益评价

- 夏普比率：（年化收益率 - 无风险收益率） / 收益率的标准差
- 索提诺比率：只计量负向波动，忽略正向波动的影响。

夏普比常用于比较不同波动性策略的表现，帮助投资者选择最优策略。但假定波动性高一定是风险高，需要收益率补偿，这样，当策略在短时间内收益大幅增长时，尽管收益表现显著提升，但标准差的增高会导致夏普比率无法真实反映策略的优异表现。而且通过调整持仓限额可以改变收益率、回撤值及标准差，但无风险利率不变，因此收益率下降速度快于标准差下降速度，导致夏普比率数值降低。

索提诺比率避免了夏普比率将正向波动视为风险的缺陷，更能准确反映策略的真实表现，尤其在波动性较高的策略中。

```python
# 计算夏普比率
# 假设无风险利率为3%
risk_free_rate = 0.03
returns = equity_curve['returns']
excess_returns = returns - risk_free_rate / 252  # 假设交易日为252天
sharpe_ratio = np.sqrt(252) * excess_returns.mean() / excess_returns.std()
results.loc[0, '夏普比率'] = round(sharpe_ratio, 2)

# 计算索提诺比率
# 只考虑下行波动率
negative_returns = returns[returns < 0]
downside_std = np.sqrt(252) * negative_returns.std()
if downside_std != 0:
    sortino_ratio = (annual_return - risk_free_rate) / downside_std
    results.loc[0, '索提诺比率'] = round(sortino_ratio, 2)
else:
    results.loc[0, '索提诺比率'] = np.inf
```

## 策略优化

### 仓位

原理上是提高波动性较低品种的持仓比例，降低波动性较高品种的持仓比例，从而保证每个品种对整个投资组合的日均盈亏波动影响接近一致。

通过波动率的度量指标（如ATR）来动态调整不同品种的持仓比例。

```python
TR = np.maximum(df['high'] - df['low'], abs(df['high'] - df['close'].shift(1)),
                          abs(df['low'] - df['close'].shift(1)))
ATR = TR.rolling(n, min_periods=1).mean()
```

ATR的意义：

- 横向比较：ATR可以在不同品种间进行横向比较，用于决定单个品种的持仓限额。
- 价格变动范围估算：ATR还可用于估算单个品种在未来某个正常交易日内的价格变动范围。

仓位计算：每个品种的风险因子设置为20个基点（0.2%），理论上，单个品种在一个交易日内的最大价值变动对投资组合整体价值的影响不超过0.2%，投资组合总价值为100万美元，每个品种的风险因子对应2000美元的价值变动。

$合约数量=\frac{0.002\times资产价值}{ATR_{100}\times该合约的点价}$

### 止损机制

入场条件带来的止损方法，一方面，在价格剧烈下跌时，可能会抹掉前期全部浮盈，另一方面，在横向震荡中，止损位置可能与当前价格非常接近，容易被短期波动洗出局。

百分比止损方法，缺乏对品种波动性的考虑，无法适应不同市场环境。

可以使用ATR获得止损位置，止损点为距开仓以来的最好价格相当于3个真实波动幅度均值的位置。

由于原始策略比较拉稀，加入止盈止损就是不断亏损。

### 多时间尺度融合

为了提高风险调整后的收益，最为广泛使用的且比较容易实现的一种办法就是将同一种交易策略应用在不同时间尺度的趋势上。只要对核心策略做出很小的调整，就可以用于捕捉时间尺度更长或者更短的趋势，这些调整包括趋势滤波器的设置、突破指标所用的天数或（和）跟踪止损的回撤点数。

如果将跟踪止损的回撤点数翻倍，在正常情况下被震荡行情弄得反复止损的时候，我们却能够更长久地保持仓位，并很可能最终因此获利。

这么做自然也有相应的缺点，因为趋势一旦真的发生反转，所遭受的损失也就会更为严重。

将跟踪止损的回撤点数减少一半，则可以在趋势反转时比别人更早地平仓，比别人更快地将利润落袋为安，但是遇到无趋势的震荡行情时也会更容易被反复止损。

### 合成期货、价差

构建一些合成合约（synthetic contract）​，也有人称为价差组合（spread）​，并将这些合约或组合当作普通的单一交易品种，前提是这些品种必须有一定的相关性。将趋势跟踪方法用在上面。

### 逆势交易

一类是逆着最主要的整体趋势进行操作，等市场出现极端行情的时候逆着趋势跟踪策略的方向进行相反的操作，但这本质上其实是趋势跟踪策略的一个风险缓冲机制；另一类的交易方向与主流趋势相同，只不过开仓的时机会选在主要趋势发生了深度的调整之后。
